SAFE-ROADS DEVELOPMENT LOG

Phase 1 – Dataset Preparation

Step 1:
Collected 6,738 raw images.

Step 2:
Converted HEIC (High Efficiency Image Container) and PNG (Portable Network Graphics) files to JPG format.

Step 3:
Resized all images to 224x224 pixels for CNN compatibility.

Step 4:
Applied horizontal flipping for data augmentation.

Step 5:
Trained initial pothole detection model on asphalt roads.

Result:
Validation Accuracy: 98%
